# Decision Log Template (Full UX)

Use this for every meaningful architectural/product decision during the phase.

## Decision ID
`FULLUX-YYYYMMDD-XX`

## Title
Short decision title.

## Context
What problem or ambiguity required this decision?

## Options Considered
- Option A
- Option B
- Option C

## Decision
Chosen option and why.

## Consequences
- Positive impact
- Trade-offs
- Follow-up work required

## Affected Docs
List files in `docs/production/fullUX/` updated because of this decision.

## Affected Code Areas
List primary files/modules impacted.

## Validation
What tests/smoke checks confirm this decision works?

## Mitigation and Recovery Plan
How to correct course quickly if this proves incorrect.
